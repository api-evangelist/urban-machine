# Urban Machine

> Urban Machine builds robotic and AI systems for sustainable wood reclamation — removing metal fasteners (nails, staples, screws) from construction and demolition lumber waste using computer vision and integrated metal detection, so the wood can be reclaimed for premium products. It is a GV-backed robotics/hardware company: it publishes no public API, but maintains an open-source ROS/Python robotics tooling footprint on GitHub.
